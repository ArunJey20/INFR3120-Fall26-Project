# ShiftTrack

## Project Description

Our project is a web application called ShiftTrack, created for our INFR3120 Web and Scripting Programming group project at Ontario Tech University. The website was designed to help employees keep track of their work shifts and verify their work hours and pay.

The website allows users to enter their shift date, start time, end time and hourly wage. The information is stored in a MongoDB database and can be viewed on the shift history page. This is the first release of our project.

## Website Pages

1. Home

The home page acts as a brief introduction to ShiftTrack and allows users to navigate to the add shift and shift history pages.

2. Add Shift

The add shift page allows users to enter their shift date, start time, end time and hourly wage. The information is saved to the MongoDB database when the form is submitted.

3. Shift History

The shift history page displays previously saved shifts in a table, allowing users to keep track of their work shifts.

## Technologies Used

The technologies used include HTML and CSS for website structure and styling, JavaScript, Node.js and Express for server-side development, EJS for displaying website content, MongoDB Atlas for database storage, Visual Studio Code for development, Git and GitHub for version control and Render for website hosting.

## Database and Cloud Deployment

We used MongoDB Atlas to store shift information and Render to deploy our website. The database connection uses an environment variable to keep our database credentials private.

## Website Testing

We tested the add shift and shift history pages locally to make sure shift information was being saved and displayed correctly. We also confirmed that the website was successfully deployed on Render and connected to MongoDB.
